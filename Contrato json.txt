Contrato Json es un documento donde definiremos las variables a usar y como se usaran para tenerlas igual.

----------SQL----------

+ Las tablas tienen nombres en plural y empiezan por mayuscula:
    Usuarios, Tareas, Habitos, Materias
    
+ Los espacios se reemplazan por un guion bajo "_":
    Registros_Habitos, racha_actual, contrasena_usuario

+ Los nombres de las columnas van en minusculas acompañado del nombre de la tabla, 
  con guion bajo como espacio y en singular:
    nombre_tarea, apodo_usuario, id_habito, fecha_registro_habito


----------Proyecto----------
----------Arquitectura de modulos----------
+ Modelo -> Se comunica con la base de datos.
+ Servicio -> El cerebro que valida.
+ Controlador -> Rutas web.

+ Nombre de archivos .py con el nombre principal en plural y el tipo seguido de un guion bajo en singular:
    usuarios_model.py,

----------Variables y funciones----------
+ Se toma el nombre de la columna omitiendo el nombre de la tabla por ejemplo:
    apodo_usuario -> Se toma solo -> apodo
